# Mechrevo R14P — Windows Drivers & Recovery

Drivers, hardware IDs and recovery instructions for the **Mechrevo R14P** laptop running Windows 11.

This repository is mainly focused on recovering the audio stack, especially the Intel Smart Sound Technology (SST) and Realtek audio drivers.

> ⚠️ This repository is intended for owners of the Mechrevo R14P and compatible hardware.
> Always verify your hardware IDs before installing a driver.

---

## 💻 Device

**Model:** Mechrevo R14P  
**Operating System:** Windows 11 (intel ver)
**Audio Codec:** Realtek ALC245 / Realtek HD Audio  
**Audio architecture:** Intel Smart Sound Technology (SST)
